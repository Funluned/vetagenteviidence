# VetEvidence AI 产品需求文档

## 1. 产品定位

VetEvidence AI 面向兽医、生物医药研究生和科研人员，把 PubMed 检索结果整理成可追溯的文献列表、期刊分区、结构化证据、带引用回答和可下载报告。

系统只辅助科研证据整理，不提供医疗或兽医诊断建议。

## 2. 用户问题

传统文献检索能返回题录，但用户仍需逐篇查找物种、模型、样本量、剂量、给药途径、结果和机制。人工整理耗时，也容易丢失来源对应关系。

## 3. 第一版目标

- 通过真实 PubMed API 检索公开题录和摘要；
- 把摘要明确报告的信息映射为固定证据字段；
- 让每条关键结论关联 PMID、DOI 和来源原句；
- 对未报告字段保持为空；
- 提供 Markdown、CSV 导出；
- 用可重复评测暴露失败和边界。

## 4. 非目标

- 不读取未授权论文全文；
- 不训练或微调大模型；
- 不做医学诊断、处方或临床决策；
- 不把动物实验结论直接外推到临床；
- 不在第一版引入多 Agent、向量数据库或复杂权限系统。

## 5. 核心用户流程

1. 用户输入病原菌、药物、疾病模型或问题；
2. 系统调用 NCBI E-utilities 获取 PMID 和摘要；
3. 分区 Provider 按 ISSN 动态查询 LetPub，解析中科院与 WOS JIF 分区；
4. 规则 Provider 提取结构化字段；
5. 系统按文献生成带引用回答；
6. 用户核查来源原句和分区来源；
7. 用户下载 Markdown 报告或 CSV 证据表。

## 7. 当前验收证据

- 自动测试：21 条通过；
- 定向评测：30/30 通过；
- 真实示范查询返回 2 篇文献；
- 目标论文 PMID `42250334`、DOI `10.1016/j.rvsc.2026.106289`；
- 浏览器已实际验证文献、证据、回答、评测和导出页面。

以上是小样本工程验收，不代表通用准确率。

## 8. 风险与下一步

- 规则无法覆盖所有摘要表达方式；
- 摘要可能省略对照、剂量和实验局限；
- 引用语义支持度仍需人工复核；
- LetPub 不是官方 API，页面结构变化可能导致解析失效；缓存和 CSV 回退只保证可用性，不替代官方复核；
- 下一版应增加不同病原、物种和药物的人工标注集，再决定是否接入 LLM Provider。
