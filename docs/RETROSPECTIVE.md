# 项目复盘

## 做对的事

- 先跑通真实 PubMed，而不是先搭复杂 Agent；
- 用 Pydantic 固定证据字段和缺失值行为；
- 把引用、来源原句和局限放在回答旁边；
- 同时保留自动测试、真实查询和浏览器交互验证；
- 将 100% 定向结果明确限制为小样本工程检查。

## 真实问题

| 问题 | 原因 | 修复 |

| 默认查询返回 0 条 | 关键词限定过多 | 缩短为核心实体组合 |

| GitHub 未上传 | 无 Git 身份、提交和远端 | 等用户提供身份与仓库地址 |

## 当前边界

- 规则覆盖有限；
- 只读摘要；
- 没有人工语义引用复核；
- 没有公网部署；
- 还没有多主题外部验证集。
