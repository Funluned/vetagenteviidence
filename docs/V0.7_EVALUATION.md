## 已知边界

- 27 个场景全部是合成工程夹具，不是公开论文、真实实验数据或科研事实。
- Retrieval Recall@3 只衡量冻结候选回放并包含部分失败恢复能力，不代表实时 PubMed、向量检索或 RAG 召回率。
- 标准答案描述理想产品行为；当前规则基线允许失败，不能为追求全绿而修改标准答案。
- 文献场景只模拟题录和摘要级输入，不能替代全文核查或领域专家复核。
- Citation Precision 与 Unsupported Claim Rate 只统计声明适用的合成 claim-citation 对，不代表全系统或 LLM 的总体比率。
- CIT-* 是预造冲突结构化记录的回答器信任边界测试，不表示规则提取器自行生成了这些错误结论。
- INJ-03 只验证 CSV 文本列不触发外部动作，不代表后续 RAG 已具备完整提示注入防护。
- 运行时网络调用和模型调用必须均为零，且不读取 API Key、用户文件或外部数据库。
- Cost 只统计模型 API Token 与实际调用费用；计算、电力和人工成本不在本版计量范围。
- Latency 是单机离线诊断值，不进入稳定结果哈希，也不能跨机器直接比较。
- 本评测不提供医疗或兽医诊断建议，也不证明任何药物组合真实有效。
- 金标准是工程验收口径；涉及科研语义的正式对外结论仍需领域人工复核。
