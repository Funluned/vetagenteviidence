# 简历项目证据稿

## 推荐项目名称

VetEvidence AI｜兽医科研证据智能体

## 简历表述

- 基于 Python、Streamlit、Pydantic 和 NCBI E-utilities 搭建兽医科研证据整理工具，实现 PubMed 真实检索、结构化字段提取、带 PMID/DOI 引用回答及 Markdown/CSV 导出。
- 设计可替换 Evidence Provider 边界；在无 LLM Key 条件下以透明规则完成病原体、物种、模型、样本量、剂量、途径、结果和机制提取，未报告字段保持为空。
- 建立 30 条定向评测，覆盖检索、引用、字段提取、缺失值和冲突保留；编写 12 条自动测试，并为 NCBI 临时故障增加重试与请求记录。

## 面试时必须如实说明

- 当前主要基于 PubMed 元数据和摘要，没有批量读取论文全文；
- 当前 Provider 是规则实现，不是训练或微调模型；
- 30/30 是针对示范查询和受控边界的定向结果，不是通用准确率；
- 项目在 Codex 辅助下完成，孙奇负责需求确认、领域判断、运行验证和项目讲解；
- 不把论文中的全部实验工作描述为孙奇个人完成。

## 不建议使用的表述

- “构建生产级医疗 AI 系统”
- “训练了生物医学大模型”
- “实现企业级多 Agent 平台”
- “达到 100% 医学问答准确率”
- “独立完成论文所有实验”
