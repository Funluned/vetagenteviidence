# VetEvidence AI 演示脚本

建议时长：4 分钟。

## 0:00—0:30 问题与定位

“科研人员在 PubMed 找到论文后，还要手工整理物种、模型、样本量、剂量、结果和机制。VetEvidence AI 把这个过程整理成可追溯证据，但不做诊断，也不把模型输出当事实。”

## 0:30—1:15 真实检索

1. 打开 `http://localhost:8501`；
2. 使用默认检索词；
3. 点击“检索 PubMed”；
4. 指出目标论文 PMID `42250334` 和 DOI；
5. 对比 LetPub 的中科院 2025 年 3 月升级版与 WOS JIF 两套分区；
6. 打开分区来源链接，说明系统按 ISSN 动态查询、缓存 7 天，失败时才用本地回退；
7. 展开摘要，说明文献元数据来自 NCBI。

## 1:15—2:00 证据表

1. 切换“证据表”；
2. 展示期刊、ISSN、两套分区、小鼠、样本量 25、Quercetin、剂量、腹腔注射、24 h；
3. 强调第二篇摘要未报告的样本量、剂量和途径保持为空；
4. 说明当前是透明规则 `rules_v1`，不是大模型猜测。

## 2:00—2:45 引用回答

1. 切换“证据回答”；
2. 指出每条结论后的 PMID 和 DOI；
3. 展开引用原句；
4. 说明只支持“摘要在该实验模型中报告相关机制”，不能外推临床。

## 2:45—3:25 评测

1. 切换“评测”；
2. 展示 30 条定向检查和分类结果；
3. 主动说明 100% 是小样本定向结果，不是通用准确率；
4. 讲一个真实错误：评测器分支顺序错误导致 28/30，修复后加回归测试。

## 3:25—4:00 导出与复盘

1. 展示 Markdown 和 CSV 下载；
2. 说明 NCBI 请求次数与 LLM 成本为 0；
3. 总结取舍：先保证真实检索、结构化字段、引用和评测，再考虑 LLM、全文和向量检索。
