# VetResearch Workbench v0.7.0 简历项目证据稿

> 候选文案：阶段 5 的本人安装、讲解、修改和排错验收完成前，不直接放入正式
> 技能栏或声称本人掌握验收已经通过。

## 推荐项目名称

VetResearch Workbench｜证据可追溯的兽医科研 Agent 工程原型

## 推荐简历表述

- 基于 Python、Streamlit、Pydantic 和 NCBI E-utilities 构建兽医科研证据工作台，
  串联 PubMed 摘要检索、透明证据分级、FICI／生长曲线分析、带 PMID／DOI／
  原文引句的报告及人工复核；缺失字段保持为空，不补造科研事实。
- 为当前任务的 PubMed 摘要和用户授权导入摘要实现本地 SQLite 索引、BM25、
  特征哈希向量、混合检索及来源／切片／授权范围／SHA-256 追溯；固定候选池
  Recall@3 为关键词 `4/5`、特征哈希 `2/5`、混合 `3/5`，据此将关键词设为
  免费默认路径，并明确不把哈希向量包装成语义 Embedding。
- 实现 DeepSeek V4 Provider、有限状态 Research Agent 和只读 Evidence Reviewer，
  对计划、五类工具、证据账本、引用、重试、Token 和人民币费用设置硬边界，
  保存模型身份、Prompt 哈希、延迟、失败和脱敏结果报告。
- 建立 27 道、九类各 3 题的版本化合成工程评测，对比规则、单 Agent 和双 Agent；
  历史全量真实 DeepSeek 运行按旧 scorer 记录单／双 `24/27`，修正 scorer 对同一
  输出离线重算均为 `22/27`；发布收口两次独立全量分别为单／双 `26/27`、`25/27`
  和 `23/27`、`24/27`，累计费用 `¥0.8775052`。Reviewer 在修复后批次改善部分
  质量指标，但历史表现波动且增加费用和延迟，因此如实保留为实验模式。
- 通过真实模型失败定位并修复账本外引用、冲突评分、证据等级、检索实体缺失、
  严格 JSON 契约和 2048→4096 单次有界截断恢复；Windows、macOS、Linux CI
  持续验证编译和全量回归。

## 面试时必须如实说明

- 免费用户可使用规则工作流和本地关键词候选检索，但免费路径不调用 LLM、
  不自动生成科研结论；实时获取 PubMed 摘要仍需要普通网络；
- DeepSeek Agent 的模型调用真实发生，但当前只运行版本化合成题和冻结工具夹具，
  尚未接入普通用户的任意问题、实时 PubMed 或工作台私有材料；
- 当前没有训练或微调模型，没有有效语义 Embedding、云向量数据库、MCP／Codex
  Skill 或企业级自治多 Agent 平台；
- Fake 单／双 Agent 的 `25/27` 只代表合同烟测，不是模型成绩；历史真实
  `24/27` 属于旧 scorer，当前代码正式复测为单／双 `23/27`、`24/27`；不同版本、
  定向和全量报告必须分别解释，不能拼分；
- 27 道题全部是合成工程夹具，gold 仍待领域专家复核；所有分数都不能外推为
  临床有效性、科研正确率或真实用户效果；
- 项目主要使用 PubMed 题录和摘要，不批量读取论文全文；报告不能替代全文、
  原始数据、验证性实验或人工最终复核；
- 项目在 Codex 辅助下完成；本人应能说明需求取舍、代码结构、真实失败、测试
  结果和边界，并完成从零安装、一次修改及排错验收后再把能力写入正式技能栏。

## 不建议使用的表述

- “构建生产级医疗／兽医 AI 系统”
- “训练了生物医学大模型或实现了有效语义 RAG”
- “DeepSeek Agent 通用科研准确率为 24/27”
- “双 Agent 显著优于单 Agent”
- “实现企业级自治多 Agent 平台”
- “支持任意用户资料、任意模型或 Codex 即插即用”
- “达到 100% 医学问答准确率或证明药物组合有效”
