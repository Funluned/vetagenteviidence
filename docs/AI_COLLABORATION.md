# AI 协作与责任边界

## 为什么披露

VetResearch Workbench v0.7.0 在 Codex 辅助下开发，并在隔离评测链中调用过
DeepSeek V4 Pro。披露 AI 参与是为了区分“开发辅助”“产品运行时模型”和
“人工科研判断”，避免把模型生成、自动测试或合成评测写成人类独立完成的科研结论。

## 三类角色

### 项目负责人

项目负责人负责：

- 确认产品目标、科研问题、证据边界和取舍；
- 决定是否使用付费模型，并逐次确认题目范围和人民币费用硬上限；
- 确认数据来源、许可、隐私和密钥使用范围；
- 审查代码差异、测试结果、失败记录和对外表述；
- 对合并、发布、部署以及最终科研解释承担责任。

自动化测试通过不等于领域结论已经由专家确认。v0.7.0 的“本人从零安装、讲解、
修改和排错”验收仍单独保留；完成前不把它写成已经掌握的正式简历能力。

### Codex 开发辅助

Codex 用于读取需求和仓库、提出实现方案、修改代码与文档、编写测试、运行验证、
定位失败并整理审计证据。它不代替项目负责人完成以下决定：

- 不自行扩大产品范围或更改科学口径；
- 不自行批准付费调用、敏感数据导入、PR 合并、Release 或仓库设置；
- 不把未公开资料、密钥、个人路径或模型原始敏感上下文写入仓库；
- 不把自己生成的文字当作外部文献或实验事实。

因此，本项目应表述为“在 Codex 辅助下完成并经测试验证”，而不是隐去 AI 参与，
也不是把全部实现归功于模型。

### 运行时 LLM Agent

DeepSeek V4 Pro 只进入隔离、显式授权的工程评测链：Research Agent 根据冻结问题
规划并调用白名单工具；这些工具返回的 PubMed 批次、本地索引和实验 CSV 也都是
合成冻结夹具，不是实时 PubMed 或用户私有资料。Evidence Reviewer 只读检查
同一份证据账本，不能重新检索或补造来源。生成结论必须引用账本内证据；证据不足或验证失败时
安全拒答或转人工复核。

默认 Streamlit 工作台不依赖 DeepSeek、Codex 或其他模型。没有 API Key 时，
规则流程和本地关键词检索仍可使用。仓库中的 Fake Provider 只是零费用合同烟测，
不是真实 LLM，其成绩不能写成模型效果。

修复后当前 v0.7.0 已独立跑完全部 27 题：单 Agent `23/27`，双 Agent
`24/27`。本批 Reviewer 改善了 Citation Precision、Unsupported Claim Rate 和
Abstention Accuracy，但 Recall 和 Task Completion 不变，规划／工具失败仍共享，且
增加 `¥0.2480774` 和中位 `13.6231 s` 延迟。结合历史批次波动，这只支持将双 Agent
保留为实验模式，不支持将它设为默认路径或宣称其稳定优于单 Agent。

## 验证方式

AI 生成或修改的实现不以“看起来合理”为验收标准，而以可复跑证据验收：

- 单元测试、集成测试和冻结基线检查；
- Windows、macOS、Linux GitHub Actions；
- 真实模型运行的请求身份、Token、费用、延迟、失败和结果哈希；
- 历史失败报告不可覆盖，不把不同代码版本的定向复测拼成新的全量成绩；
- 单 Agent 与双 Agent 使用同一评测集和同一份 Research 状态比较；同时报告当批
  改善、额外成本和跨批次波动，不用单次优势宣称稳定收益。

详细结果见 [v0.7.0 Agent 评测说明](V0.7_AGENT_EVALUATION.md) 和
[真实 Agent 失败与修复案例](REAL_AGENT_FAILURE_CASE.md)。

## 敏感信息保护

- API Key 只通过运行环境提供，不进入代码、提交、报告、截图或日志；
- 真实付费调用必须显式选题、确认调用并设置正数费用硬上限；
- 默认评测输入为版本化合成工程场景，不包含未公开论文、实验原始数据或个人信息；
- 模型只接收完成当前评测所需的最小上下文，标准答案留在评分器一侧；
- 本地索引和运行记录默认保存在 `.workbench`，发布前仍须执行敏感信息扫描。

## 对外表述边界

可以证明的是：免费产品实现了可追溯的本地关键词候选检索，但不调用 LLM、也不
生成科研结论；隔离的真实 Agent 评测链则在冻结合成夹具上完成了检索增强生成、
工具调用、Evidence Reviewer、费用控制和失败关闭流程。两条路径不能合并宣传成
“免费用户已经获得语义 RAG Agent”。

不能据此声称：这是企业生产级多 Agent 平台、模型经过训练或微调、合成评测代表
通用科研准确率、计算预测等于实验结论，或系统能够提供医疗与兽医诊断建议。
