# VetResearch Workbench v0.3 演示脚本

建议时长：6 分钟。使用仓库自带的合成导入、实验和网络关系演示文件，
文献检索使用真实 NCBI PubMed。

## 0:00—0:30 问题与定位

“VetEvidence AI v0.1 已经解决了真实 PubMed 检索、结构化提取和逐条引用。
VetResearch Workbench v0.3 在这个底座上完成问题拆解、多来源证据、实验
数据分析、网络药理学、分子对接、决策报告和人工审计。当前只聚焦候选
药物与抗生素协同作用，不做诊断，也不把计算预测当成实验事实。”

打开 `http://localhost:8501`，指出顶部六步标签：

1. 问题与假设；
2. 文献证据；
3. 实验数据；
4. 机制预测；
5. 决策报告；
6. 运行记录。

## 0:30—1:10 问题与假设

1. 先选择“证据不足负例”：`quercetin` 与 `amoxicillin` 对 `Streptococcus agalactiae` 是否具有值得进一步验证的协同作用；
2. 点击“创建或重置研究任务”；
3. 展示系统生成的 2—4 条假设、验证方法、成功标准和生成规则；
4. 轻微修改一条假设并保存；
5. 强调修改会写入运行记录，自动生成的 PubMed 检索式对用户可见。

讲解要点：

> 问题拆解使用透明规则，不依赖 LLM；用户可以在检索前审阅和修改假设。

## 1:10—2:10 多来源文献证据

1. 切换“文献证据”；
2. 点击“执行 3 轮 PubMed 检索”；
3. 展示负例结果：8 篇文献全部只能作为间接背景，直接文献证据为 0；
4. 生成报告，指出系统明确写出“仅凭本次文献检索不能判断或宣称存在协同作用”，而不是强行下结论；
5. 选择“公开直接文献证据正例”，执行 `florfenicol + thiamphenicol / Pasteurella multocida` 检索；
6. 展示本次复跑中唯一通过严格准入的 PMID `31749775`，打开详情核查 DOI、摘要、直接证据理由及原句；
7. 说明本次复跑中的其余结果仍可展示，但只能作为背景，不能进入协同结论。

讲解要点：

> “当前检索未发现直接文献证据”不等于“已经证明不存在协同”。真实、匹配药物对的实验 CSV 使用独立证据链呈现；数量和排序会随 PubMed 更新，结论必须限定在当前可见检索结果。

> 合成 RIS 只用于演示解析与条件提取，不是科研事实；系统不会绕过知网权限自动抓取。

## 2:10—3:10 实验条件与 CSV

1. 切换“实验数据”；
2. 展示统一实验条件矩阵：来源、物种、模型、样本量、干预、剂量、时间、对照、指标和缺失字段；
3. 展开一致性、显式冲突与证据空白；
4. 选择 `FICI`，点击“分析合成 FICI 演示”；
5. 展示逐行 FIC/FICI、分类、有效行数和原始行；
6. 指出合成演示当前产生 2 行协同和 1 行相加结果；
7. 如需切换演示，选择“生长曲线”，展示时间点均值、标准差和分组 AUC。

讲解要点：

> FICI 和生长曲线都是描述性分析。FICI 不能替代独立重复与 time-kill；AUC 不能替代预先登记的统计推断。

> 坏行不会被静默忽略，原始值、CSV 行号和错误都会进入审计。

## 3:10—4:10 机制预测

1. 切换“机制预测”；
2. 点击“加载合成网络演示”，展示两个带 `SYNTHETIC` accession 的数据源、
   输入 SHA-256、交集靶点和透明网络分数；
3. 强调这些靶点是流程演示，不是科研事实；
4. 展示配体、受体 PDBQT、来源 accession、搜索框、随机种子和 Vina 版本
   输入区；
5. 说明系统先生成不含分数的任务清单，本机不捆绑也不自动运行 Vina；
6. 用户导入的 Vina 文本只有任务清单哈希与版本一致、且包含合规的
   mode/affinity 表时才能导入；格式校验不能认证文件确由 Vina 实际运行产生。

讲解要点：

> 网络排名与对接得分始终标为计算预测，不能单独证明结合、抗菌活性或协同。

## 4:10—5:10 决策报告与人工复核

1. 切换“决策报告”；
2. 点击“生成或刷新决策报告”；
3. 展示可检验假设、可追溯结论、冲突、证据空白、风险和下一步建议；
4. 指出文献结论后的 PMID、DOI 或来源片段，以及 CSV 结论中的文件名、SHA-256、原始行号和计算过程；
5. 强调合成分析结论带有“不可作为科研证据”标签；
6. 下载 Markdown 或 JSON 审计报告；
7. 输入复核意见，选择“要求修改”或“通过”，保存人工复核。

讲解要点：

> 没有可追溯来源时系统拒绝生成报告。报告只能帮助确定下一步实验，不是诊疗或临床建议。

## 5:10—5:40 运行记录与恢复

1. 切换“运行记录”；
2. 展示当前状态、事件数、工具调用数和失败记录；
3. 查看问题拆解、PubMed 检索、文献导入、CSV 分析、报告生成与人工复核事件；
4. 指出本地文件 `.workbench/runs/<run_id>.json`；
5. 下载完整运行快照；
6. 复制页面显示的完整运行 ID，在“恢复历史运行”输入并恢复。

如果需要演示失败与重试，可上传一个缺少必需列的 CSV，查看失败事件后改用模板重试；失败记录不会因后续成功而消失。
